# 005 交互设计

收件箱页面只回答一个问题：**现在有什么需要我？** 原型面板的另外两个问题（系统是否健康、某件工作的完整历史）不在这里回答，前者留给后续的 work-item 插件，后者就是 Session 本身。

页面遵循原型 [005 Panel](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/main/docs/005-panel.md) 的原则：只放重要的东西、定义明确、计数诚实、默认安静、使用 DSH 的设计 token。

## 入口

- 侧栏 `sidebar.panellist` 里放一个图标。
- 徽标显示 `system` + `hard` 类型的打开义务数，为 0 时不显示；有 `system` 义务时徽标用警示色。
- 不弹窗，不发系统通知，不加 toast。

## 页面结构

### 分组

| 分组 | 内容 | 出现条件 |
|---|---|---|
| 系统 | `system` | 有条目时才显示 |
| Agent 在等你 | `hard`：审批、计划、提问 | 有条目时才显示 |
| 待你决定下一步 | `soft`：goal 受阻、轮次失败、待验收 | 有条目时才显示 |

分组之间、组内条目的顺序见 [001](001-domain.md) 的"排序"一节。分组标题上的数字就是这个分组的条目数。

### 条目的组成

1. **第一行**：类型标签，加上一句话说明在等你做什么（`title`）。标签说的是"它需要什么"，不是内部状态码（原型面板原则 2）。
2. **第二行**：主体（Workspace › Session 标题）· 等了多久 · 截止时间（如果有）。`certainty: 'inferred'` 的条目在这里加一个小的"推断"标记，悬停时解释推断依据。
3. **动作**：最多两个主动作直接显示，其余放在"更多"里。推荐选项排在最前，和 `ask_user_question` 的约定一致。
4. **详情**（`detail`）默认折叠，点击条目展开。

### 动作的反馈

- 点击后，条目进入"处理中"状态，按钮禁用。
- 事实发生变化后，条目淡出；页面顶部出现 3 秒"已处理 · 撤销不可用"的轻提示（审批类动作在 DSH 里本来就不能撤销，这里如实告诉用户）。
- 5 秒内事实没有变化：显示错误原因，并提供"打开 Session"。

### 键盘

| 键 | 作用 |
|---|---|
| `j` / `k` | 下一条 / 上一条 |
| `Enter` | 执行推荐动作（审批类：允许一次） |
| `Esc` | 审批类：拒绝 |
| `o` | 打开主体 |
| `s` | 稍后提醒（默认 1 小时） |
| `x` | 忽略（硬阻塞类型需要二次确认） |

`Enter` 和 `Esc` 的语义和原生审批面板一致（`dsh-client-ui-approval`），用户不需要学两套按键。

## 空状态

空状态要让人一眼看出“它在替你盯着”，而不是一页空白。只用真实数据，不放假示例：

- 大标题“一切都在跑，没有需要你的事”，副标题写出正在盯着的 Session 数。
- 雷达卡片：正在跑的 Agent、刚跑完的 Session（可点击打开）；没有在跑的 Agent 时给一句开始任务的提示，并用三行说明能在这里做什么。
- 一轮处理完清空时显示勾选动画和“这一轮你在这里处理了 N 件事，一次都没切走”。
- 下方三个数字：今天在这里处理、今天替你挡掉、中位响应。

有待办时，标题变成“N 个 Agent 停下来在等你”和最久等待时长；每张卡片实时计时，处理成功后在页面内显示 3 秒“搞定，没离开这一页”。仍然不弹窗、不发系统通知。

## 稍后提醒与静音

- **稍后提醒**：1 小时、今晚、明早、自定义时间。到期时条目回到原位置，等待时长按最初出现的时间计算。
- **静音**：只针对 `soft` 类型，范围可以是"这个 Session"或"这个 Workspace"，例如"这个 Workspace 的待验收不用提醒"。`hard` 和 `system` 不能静音，因为 agent 真的停下来了，静音只会让它一直等下去。
- 静音规则集中显示在设置页里，可以随时撤销。

## 设置页（在页面右上角，同时挂到 `settings.section`）

v1 只有这几项，**全部有默认值**，不改也能正常使用：

| 设置 | 默认 | 说明 |
|---|---|---|
| 静音规则 | 无 | 只能在条目上添加，在这里查看和撤销 |
| 待验收（`review`）类型 | 开 | 觉得吵可以整体关掉 |
| 账本保留天数 | 90 | |
| 异步提问（v1.1） | 关 | 开启后 `ask_user_question` 超时会释放 agent 去做别的，你之后在收件箱里回答。开启前会说明这会改变 agent 的行为 |

## 语言

所有文字都放在 `locale/zh.json` 和 `locale/en.json` 里，跟随 DSH 的语言设置。术语和 [README](README.md) 中的术语表一致。

## 视觉与排版（2026-11-25）

收件箱和每日笔记共用一套页面骨架和主题，限定在 `.dsh-cn` 范围内。所有颜色、圆角、阴影、字号和动效都取自 DSH 自己的设计变量（`--dsw-alias-*`、`--dsw-radius-*`、`--dsw-elevation-*`、`--ds-transition-*`），所以深浅色由 DSH 自动切换，观感和原生界面一致。DSH 原生设置页里的收件箱设置仍沿用宿主样式。

**骨架**（两个页面相同）
1. 吸顶工具栏，44px：左侧是面包屑，右侧是页面操作（设置、钉到对话旁）；背景半透明并带模糊。停在顶部时没有边线，内容滚到它下面后才淡入一条细线。
2. 紧凑页头：24px 线条图标（不加底色块）、22px 粗体页名，下面是一行状态导语，数字带状态色。
3. 一排属性（Notion 页面属性的样子：没有边框和底色，悬停时才有浅底）：收件箱是「正在盯着 N 个 Session / 今天在这里处理 / 替你挡掉 / 中位响应」，原来的三个统计格子并入这里；笔记是「日期 / 你的时间 / Agent 派发」。
4. 视图切换（只有笔记有：笔记、时间线），右侧放状态筛选，下面一条细线。没有视图切换的页面（收件箱），用同样一条细线把页头和正文分开。
5. 主栏加右侧栏：正文栏最大 1040px。面板宽度 ≥ 880px 时（按容器宽度判断，不按窗口），出现 248px 的固定右侧栏，和主栏之间留 48px 空白，不画分隔线：收件箱放「今天的计划」「正在跑」「刚跑完」，笔记放「今天」日程、「昨天」小结和「近 30 天」趋势。宽度不够时右侧栏排到主栏下方。
6. 页脚：快捷键，以及「这些数字怎么来的」；不加顶部分隔线，靠留白分开。

**文案与语言（2026-11-25）**
- 所有界面文字跟随 DSH 的界面语言（中文 / 英文），两套词典键完全一致，由 `tests/locale.test.mjs` 检查。中文用 DSH 自己的说法：「会话」「工作区」，不夹英文的 Session、Workspace、Host。
- 类型标签说清楚要你做什么：需要批准、需要回答、计划待批准、目标受阻、运行出错、待验收。
- 模型服务返回的原始错误（通常是英文）不再直接当标题。卡片标题是用你的语言写的说明和下一步，比如「没有配置模型的 API Key……到『设置 › 模型』填好后，打开会话重试」；原文折叠在「原始信息」里。目前识别：没有 API Key、Key 无效、余额或额度不足、限流、上下文过长、网络或超时、服务端错误、输出被截断、被打断、被拦下；其余显示通用说明加原文。
- 后台自己生成的占位文字（如「Plan review」「Approve」「Keep planning」、中英混排的待验收标题）在显示时换成当前语言；回答计划时发给 DSH 的仍是原始选项，不影响原生流程。
- Agent 写的内容（提问、计划、会话标题、结论）按原样显示，不做翻译。

**分区方式（Notion 风格，2026-11-25 第二轮）**
- 不用卡片和阴影分区。区块之间靠留白；只在需要扫读的列表里用 1px 细线（`--dsw-alias-border-l1`）。
- 收件箱的待办是列表块：块与块之间一条细线，悬停时整块出现浅底；浅底向左右各多出 10px，正文仍和页面左边对齐。被选中的块用 7% 的品牌蓝底色，悬停或选中时，相邻的分隔线隐藏。
- 右侧栏的「今天的计划」「今天」「近 30 天」等是带小标题的列表，不是卡片：12px 浅色小标题，下面是可悬停的行，区段之间留 24px。
- Agent 写回的结论用引用块样式（左侧 2px 竖线，无底色）；出错和警告仍是带底色的提示块。
- 颜色、圆角、字号和动效仍全部取自 DSH 变量，深浅色跟随 DSH。

**排版尺度**
- 间距按 4px 网格。
- 字号：正文 14px，次要文字 13px，辅助信息 12px，页名 22px，与 DSH 对话区一致。
- 行高 30px。
- 行尾信息（日期、状态标签）对齐成固定的一列。悬停操作浮在行尾上方，用渐变遮罩衔接，不占布局空间。
- 时间线是固定列网格：状态 / 标题 / 标记 / 日期 76px / 谁做 64px / 占用 92px，带表头。
- 设置页是「说明 | 220px 控件」两栏。

**动效**
- 全部使用 DSH 的时长（.1s / .2s / .3s）和缓动 `cubic-bezier(.4,0,.2,1)`。
- 页面、行、列表块进场时轻微淡入并上移 3px。视图标签的下划线、折叠三角、进度条宽度、开关、悬停按钮都有过渡。
- 系统开启「减少动态效果」时，全部动效关闭。

**窄屏与触屏**
- 宽度 ≤ 640px 时，时间线只保留标题列，日期行的统计换到第二行，设置页改为单栏。
- 没有悬停能力的设备（触屏），操作按钮只在聚焦的那一行显示。
- 任何宽度下都不出现横向滚动。
